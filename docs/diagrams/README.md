# Diagram sources

Mermaid sources of the diagrams shown as images in the README and the admin guide
(`docs/images/workflow.png`, `architecture.png`, `deployment.png`). The docs use PNG images rather
than inline Mermaid so that GitHub shows a plain picture without its pan and zoom controls.

To change a diagram, edit the `.mmd` file here, render it (for example at <https://mermaid.live>,
or with `npx @mermaid-js/mermaid-cli -i workflow.mmd -o workflow.png -s 2 -b white`), and replace
the PNG in `docs/images/`.
